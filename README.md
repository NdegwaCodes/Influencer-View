# Influencer View

Influencer View is a web application designed to help influencers track and manage their campaign submissions. It provides features for viewing ongoing campaigns, tracking submission statuses, and monitoring performance metrics.

## Features

- **Campaign List Page**: Displays a list of campaigns with their statuses and deadlines.
- **Campaign Details Page**: Shows detailed instructions for each campaign and allows influencers to upload their submissions.
- **Performance Snapshot**: Displays metrics such as total posts submitted, posting dates, and estimated engagement.
